# thorsten-hillmann.de

Persönliche Website von Thorsten Hillmann: Live-Keyboard-Sounds, Tablet-Halterungen, Workshops.

- `index.html` – Startseite (DE/EN, Sprache per Umschalter bzw. Browsersprache)
- `datenschutz.html` – Datenschutzerklärung (Entwurf, vor Livegang prüfen lassen)

Gehostet über GitHub Pages. Die Domain wird erst nach Freigabe per `CNAME`-Datei und DNS-Umstellung verbunden.
